# Modern Family Wellness — Landing Page

A polished partnership landing page for [@modernfamilywellness](https://instagram.com/modernfamilywellness).

## Preview locally

```bash
cd website
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080)

## Customize before sharing

1. **Email** — Update `hello@modernfamilywellness.com` in `index.html` and `script.js` to your real inbox.
2. **Instagram handle** — Confirm `@modernfamilywellness` is correct in the social links.
3. **Names & photos** — Add your names and a hero photo in the About section if desired.
4. **Contact form** — The form opens the user's email client. For automatic delivery, connect it to [Formspree](https://formspree.io), [Netlify Forms](https://docs.netlify.com/forms/setup/), or similar.

## Deploy (free options)

- **Netlify**: Drag the `website` folder to [app.netlify.com/drop](https://app.netlify.com/drop)
- **Vercel**: `npx vercel website`
- **GitHub Pages**: Push the `website` folder and enable Pages from that directory

## Files

- `index.html` — Page structure and content
- `styles.css` — Visual design
- `script.js` — Navigation, scroll effects, contact form
