# Dr. Jonathon Ross — Chiropractic Website

Static landing page for the functional neurology & movement practice.

## Preview locally

```bash
cd websites/chiropractic && python3 -m http.server 8081
```

Open [http://localhost:8081](http://localhost:8081)

## Customize

- Phone, email, and social links in `chiropractic/index.html` and `chiropractic/script.js`
- Clinic addresses in the Locations section
- Education articles in `chiropractic/education/`
